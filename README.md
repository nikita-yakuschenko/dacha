# «Просто Дача» — пакет материалов для разработки на Next.js

## С чего начать

1. Распакуйте архив в рабочую папку или рядом с репозиторием.
2. Откройте файл `CODEX_PROMPT.md` и передайте его Codex с доступом к содержимому папки.
3. `source/` — исходные материалы пользователя (два ZIP, standalone HTML, Markdown бриф).
4. `references/visual-concepts/` — девять визуальных концептов **только как арт-дирекшн**. В них могут быть вымышленные детали и цены.
5. `references/logo/` — векторизованный утверждённый логотип; используйте именно его SVG, не набирайте слово заново.

## Что уже подтверждено

Единственный товар — дачные/садовые сезонные дома. Три пилотных размера: 4×5, 4×6, 5×6 м. Комплект с доставкой и дом с монтажом — отдельные пути. Доставка ориентирована на Центральную/Южную Россию, монтаж — Нижегородская область и примерно до 500 км от Нижнего Новгорода после проверки маршрута.

## Что НЕ подтверждено

Цены и скидки, площади комнат, материал конкретных окон/кровли, сроки изготовления, гарантии, фото построенных объектов, контактные данные, юридические документы. Не использовать цифры и обещания из иллюстраций как подтверждённые сведения.

## Дизайн-ориентиры

Фирменный зелёный `#2D4938`; тёплый светлый `#F5F2E9`; текст `#202820`; границы `#DCE2D9`. Логотип монохромный. Шрифт интерфейса — [Medeo Sans](https://prtner.ai/font/ru/) (пакет `medeo-font`, OFL 1.1). Текст логотипа — векторные контуры.

## Обязательные design skills в Codex

- https://github.com/pbakaus/impeccable — `impeccable`.
- https://github.com/emilkowalski/skills — `emil-design-eng`, `apple-design`.

## Реализованный сайт

Next.js 16.4.5 (App Router), React 19, TypeScript strict, Tailwind CSS 4, локальные shadcn/ui и Tabler Icons.

```powershell
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:3000. Production: `npm run build`, затем `npm run start`.

Docker: `docker compose up --build -d`. Инструкция и параметры: [docs/DOCKER.md](docs/DOCKER.md).

Проверки: `npm run lint`, `npm run typecheck`, `npm run test:ui` (сначала `npx playwright install chromium`).

Главная `/` — лендинг. Проекты открываются в крупном диалоговом окне внутри страницы; отдельных маршрутов проектов нет. Страница `/contacts` сохранена. Блок быстрого выбора в hero временно закомментирован по указанию пользователя.

Формы демонстрационные: заявки не отправляются. Подключение сервиса и документов описано в [docs/INTEGRATION.md](docs/INTEGRATION.md), происхождение и замена изображений — в [docs/ASSETS.md](docs/ASSETS.md), результаты — в [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md).
