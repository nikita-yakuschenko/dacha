# Изображения и замена контента

Hero обновлён на изображение, переданное пользователем: `public/images/hero-garden.webp`, исходник `docs/assets/hero-garden-source.png`. Используется без генеративных изменений, только конвертация в WebP. Desktop: вся ширина контейнера и светлая CSS-маска слева; mobile: текст над изображением с плавным светлым переходом. Видимых подписей поверх изображения нет.

## Новые миниатюры проектов

По отдельному запросу пользователя через встроенный imagegen созданы три изолированных рендера на прозрачном фоне: `public/images/dacha-20-thumbnail.webp`, `dacha-24-thumbnail.webp`, `dacha-30-thumbnail.webp`. Каждый промпт задаёт соответствующий наружный размер и единый ракурс по пользовательскому примеру. Оригиналы и точные prompts находятся в `docs/assets/dacha-<20|24|30>-thumbnail-original.png` и `dacha-<20|24|30>-thumbnail.prompt.txt`; provenance рядом с каждым WebP. Альфа-канал сохранён, рабочая ширина720px. Поле `thumbnail` централизовано в `src/lib/data.ts`, используется в поп-апах и сохранённом компоненте быстрого выбора. Видимые пометки поверх изображений удалены по прямому указанию пользователя. Блок быстрого выбора временно отключён, поп-апы используют новые рендеры.

`public/brand/logo.svg`, `logo-white.svg` и `src/app/icon.svg` — исходные SVG из references/logo; контуры и геометрия сохранены без изменения.

`public/images/garden-concept.webp` — новая иллюстрация, созданная встроенным imagegen 4 ноября 2026. Это общий концептуальный образ, а не утверждённый фасад Дачи 20/24/30 и не фотография построенного объекта. В каждом использовании есть видимая маркировка. Полный исходный prompt: [garden-concept.prompt.txt](assets/garden-concept.prompt.txt). Оригинал: `docs/assets/garden-concept-original.png`. WebP 1536×1024, quality 84; выдаётся через next/image с адаптивным sizes. Фото конкурентов и нарезка скриншотов не использованы.

Для замены: добавьте утверждённые изображения в `public/images`, заполните `image` в `src/lib/data.ts`. Передайте путь в HouseImage; измените caption только после подтверждения происхождения. Для реальных фасадов каждой модели используйте отдельные фото, размеры width/height и alt. Если утверждено именно фото, уберите слово «концептуальная», сохранив достоверную подпись.

Планы: поле `plan` остаётся null до получения проверенных файлов. Текущий Plan отображает только наружный прямоугольник по подтверждённым размерам. Комнаты, мебель, двери и окна не придуманы. Перед включением плана добавьте полноразмерный просмотр/масштабирование для мобильного экрана.

Цены, полезная площадь, толщина стен и площадь террасы — null, спецификация pending. Подтверждённые значения следует вводить централизованно в `src/lib/data.ts`, одновременно обновляя рендер соответствующих pending-состояний. Не менять только текст поверх заглушек.
